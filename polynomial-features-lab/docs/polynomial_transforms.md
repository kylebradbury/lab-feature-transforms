I would like to create a separate interactive lab that focuses on going from the raw features x_1 and x_2 to polynomial transforms. I'd like to have the biggest plot be the original features space. There should be a smaller plot of a subspace of the transformed feature space where we can drag and drop any of the transformed components on the plot to view them on either the horizontal or vertical axis.

The idea for each of these is that there should be a series of challenges (as there is in the current "Challenge" section) but each represented by different datasets of increasing difficulty. Each challenge should start with the student seeking to manually set the model parameters to maximize training accuracy. Once the student has done what they can optimizing it, they should be able to hit a button to reveal the logistic regression best fit and be able to compare their solution to that best fit solution and see how it compares. There should also be a button to reset in case they get lost or want to try again.

The manual controls for the weights should be easily accessible while viewing the plots (currently you have to scroll a bit on a typical screen, which makes it more difficult). Additionally, the equation representing the boundary should be visible at all times and shown prominently so the students can see exactly how their adjustments impact the model's decision boundary.

At any point they should be able to move onto the polynomial features and for this exercise should be restricted to second order polynomials. The should be able to include only a subset of transformed features if they like as they can now in the polynomial section. There should always be the plot that shows the relative weights for each of the input features alongside a plot that enables they to view any selected two of the available features.
